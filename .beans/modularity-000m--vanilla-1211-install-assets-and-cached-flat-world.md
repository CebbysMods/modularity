IO half of the launcher: everything the game needs before a loader is involved.

## Classes
- `Assets` — download the asset index, write `assets/indexes/<indexId>.json`, objects to
  `assets/objects/<first2>/<sha1>`. Reuse the Loom cache when present (`~/.gradle/caches/fabric-loom/assets`,
  ~1.3 GB, `indexes/1.21.1-17.json`) by copy/hardlink; otherwise download from `resources.download.minecraft.net`.
- `MinecraftInstall` — from `piston-meta.mojang.com/mc/game/version_manifest_v2.json`, ensure the 1.21.1 version
  JSON, client jar, server jar, all vanilla libraries and the asset index/objects in the shared cache. Write
  `versions/1.21.1/{1.21.1.json,1.21.1.jar}` so `inheritsFrom` resolves uniformly for every loader.
- `SmokeWorld` — one cached flat world per Minecraft version, generated by the vanilla server
  (`downloads.server`, `--nogui`), `eula.txt` and the `SmokeSetup.prepareServer` properties, `stop` after
  `Done (`, copy `smoke/` out and delete `session.lock`.

## Notes
- Cold download is ~850 MB of assets plus libraries; the precheck must fail fast on a missing index object.
- Shared state between four platform projects: guard the cache with a `maxParallelUsages=1` build service.

## Acceptance
- A second run starts instantly from the cache (no downloads).
- `versions/1.21.1/1.21.1.jar` and the asset index are present and checksum-verified.
- The cached world opens in vanilla 1.21.1.
